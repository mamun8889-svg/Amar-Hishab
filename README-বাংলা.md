# আমার হিসাব

ব্যক্তিগত হিসাব + একাধিক ফান্ড/ম্যানেজমেন্ট (মক্তব, মসজিদ ইত্যাদি) + একাধিক ব্যবহারকারী + অনলাইন ব্যাকআপ।
কোনো বিল্ড-টুল লাগে না — `www/` ফোল্ডারই পুরো অ্যাপ।

## ১. এখনই চালিয়ে দেখুন (লোকাল মোড)
`www/` ফোল্ডার যেকোনো ওয়েব সার্ভারে রাখুন (বা `npm run serve`)। প্রথমবার খুললে **সুপার এডমিন** অ্যাকাউন্ট খোলার পাতা আসবে।
অ্যাকাউন্ট খুললে Amar Hishab.xlsx ও মক্তব ব্যবস্থাপনা সিস্টেম.xlsx-এর সব তথ্য হুবহু ঢুকে যাবে (সব সম্পাদনাযোগ্য)।
লোকাল মোডে তথ্য শুধু ওই ফোনের ব্রাউজারে থাকে — অনলাইন ব্যাকআপ ও অন্য ফোনের লগইন নেই।

## ২. অনলাইন ব্যাকআপ ও সবার আলাদা লগইন চালু করা (Firebase, বিনামূল্যের প্ল্যান যথেষ্ট)
1. console.firebase.google.com → **Add project**।
2. **Build → Authentication → Get started → Sign-in method → Email/Password** চালু করুন।
3. **Build → Firestore Database → Create database** (Production mode; অঞ্চল: asia-south1 বা asia-southeast1)।
4. Firestore → **Rules** ট্যাবে `firestore.rules` ফাইলের পুরোটা পেস্ট করে **Publish**।
5. Project settings → Your apps → **Web (</>)** → অ্যাপ রেজিস্টার করে যে `firebaseConfig` পাবেন তার মানগুলো `www/js/config.js`-এ বসান।
6. অ্যাপ খুলুন → **প্রথম অ্যাকাউন্টই সুপার এডমিন** (তাই নিজে আগে খুলুন)। এরপর "অ্যাডমিন প্যানেল" থেকে বাকিদের আইডি খুলে দিন, বা লগইন পাতায় নিবন্ধন চালু রাখুন।

**কে কী দেখে:** প্রত্যেকে শুধু নিজের ব্যক্তিগত খাতা দেখে। সুপার এডমিন সবার খাতা দেখতে ও বদলাতে পারে। ফান্ড দেখতে পায় শুধু সে, যাকে ফান্ডের "সেটিংস → সদস্য" থেকে যোগ করা হয়েছে (দর্শক বা সম্পাদক)।

**পাসওয়ার্ড হারালে:** ইমেইল দিয়ে খোলা অ্যাকাউন্টে "পাসওয়ার্ড ভুলে গেছেন?" কাজ করে। সাধারণ আইডির (যেমন `rahim`) পাসওয়ার্ড অ্যাপ থেকে রিসেট করা যায় না — Firebase-এর সীমাবদ্ধতা। তাই গুরুত্বপূর্ণ অ্যাকাউন্টে ইমেইলকে আইডি হিসেবে ব্যবহার করুন।
সুপার এডমিন কাউকে "বন্ধ" করতে পারে, কিন্তু অ্যাকাউন্ট মুছে ফেলতে পারে না (সেটা Firebase Console থেকে করতে হয়)।

## ৩. APK বানানো
**সহজ উপায় (কম্পিউটারে কিছু ইনস্টল ছাড়া): GitHub Actions**
1. একটি GitHub রিপোজিটরিতে এই পুরো ফোল্ডার আপলোড করুন।
2. **Actions → "APK তৈরি" → Run workflow**। ৫–১০ মিনিট পর **Artifacts → amar-hishab-apk** থেকে `app-debug.apk` নামান।
3. ফোনে ইনস্টল করুন (অজানা উৎস থেকে ইনস্টলের অনুমতি লাগবে)।

**নিজের কম্পিউটারে:** Node 20 + JDK 17 + Android SDK থাকলে `npm install && npx cap add android && npm run apk`।

**অ্যাপ বদলালে:** `www/` ঠিক করে আবার বিল্ড করুন। Firebase config বদলালেও আবার বিল্ড লাগবে।

## ৪. ফাইলের মানচিত্র
- `www/js/config.js` — Firebase মান বসানোর জায়গা
- `www/js/seed.js` — দুই শিট থেকে রূপান্তরিত তথ্য (`tools/make-seed.mjs` সব মোট শিটের সাথে মিলিয়ে তৈরি করে)
- `www/js/data.js` — লোকাল/ক্লাউড ডেটা স্তর, `app.js` — স্ক্রিন, `ui.js` — ফর্ম ও শিট
- `firestore.rules` — নিরাপত্তা নিয়ম
- `.github/workflows/build-apk.yml` — APK বিল্ড

## ৫. নতুন ম্যানেজমেন্ট (যেমন মসজিদ) যোগ করা
ফান্ড → "নতুন ম্যানেজমেন্ট যোগ করুন" → নাম, চিহ্ন, বাবদ (জেনারেল, ইত্যাদি) দিন। কালেকশন, খরচ, বাবদভিত্তিক ব্যালেন্স, ঘাটতি সতর্কতা ও পরিচিতির তালিকা আপনা-আপনি পাবেন।

## ৬. ব্যাকআপের নিয়ম
- অনলাইন: "আমি → এখন অনলাইন ব্যাকআপ নিন" (স্ন্যাপশট) — আর সব এন্ট্রি এমনিতেই ক্লাউডে জমা হয়।
- ফাইলে: "ফাইলে ব্যাকআপ (JSON)" ও "ফাইল থেকে ফেরান"। CSV-ও নামানো যায়।
